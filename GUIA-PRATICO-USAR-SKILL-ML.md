# 🚀 SKILL: Auditoria Completa + Alterações Prontas para Mercado Livre

## Objetivo
Fazer auditoria profissional do anúncio no Mercado Livre, identificar erros, sugerir melhorias específicas e entregar as alterações prontas para você copiar, colar e publicar diretamente na plataforma.

## O que essa skill faz
✅ Analisa titulo, descrição, fotos e características  
✅ Identifica bloqueios de conversão  
✅ Mostra exatamente o que está errado  
✅ Sugere versões melhoradas  
✅ Fornece instruções passo a passo de como alterar  
✅ Explica o motivo de cada mudança  
✅ Estima impacto nas vendas  

## Quando usar
- Antes de publicar um novo anúncio
- Quando conversão está baixa
- Quando recebe poucas visualizações
- Para revisar anúncios existentes
- Para aumentar vendas de forma comprovada

## Parte 4: Implementando as Alterações

### PASSO 1: Editar Título

No Mercado Livre:
```
1. Abra seu anúncio
2. Clique em "Alterar" ou "Editar anúncio"
3. Na aba "Informações básicas", clique no campo "Título"
4. Limpe completamente (Ctrl+A, Delete)
5. Cole a sugestão nova do ChatGPT
6. Clique em "Continuar" ou "Salvar"
7. Pronto!
```

### PASSO 2: Editar Descrição

```
1. No anúncio, clique em "Editar"
2. Vá até "Descrição do anúncio"
3. Delete tudo (Ctrl+A, Delete)
4. Cole a descrição nova (Ctrl+V)
5. Se tiver muitas fotos/imagens, ajuste a ordem
6. Clique em "Continuar" ou "Publicar"
7. Pronto!
```

⚠️ **CUIDADO:** 
- Não cole descrição em Word e depois no ML (perde formatação)
- Copie direto do ChatGPT
- Se ficar muito grande, divida em seções

### PASSO 3: Reordenar Fotos

```
1. Edite o anúncio
2. Vá até "Galeria de fotos"
3. Procure pelo ícone de "setas" ou "arrastar"
4. Arraste a foto para reordenar
5. A primeira foto é a mais importante!
6. Salve
```

### PASSO 4: Preencher Características

```
1. Edite o anúncio
2. Vá até "Características" ou "Atributos"
3. Preencha todos os campos solicitados
4. Seja preciso (ex: "50 cm" não "aproximadamente 50")
5. Salve
```

## Parte 7: Se Algo Não Funcionar

### Problema: Visitas caíram

**Possível causa:** 
- Mudou muita coisa de uma vez
- Texto ficou muito longo
- Fotos ficaram piores

**Solução:**
- Espere 7 dias (ML precisa reindexar)
- Se piorar, reverta para a versão anterior
- Procure um segundo parecer no ChatGPT

### Problema: Conversão não melhorou

**Possível causa:**
- Anúncio está bom, mas público é errado
- Preço muito alto
- Falta prova social (avaliações)

**Solução:**
- Reduza o preço temporariamente (gera vendas = avaliações)
- Mude o público-alvo nos anúncios pagos (se usar)
- Peça avaliação ativa após entrega

### Problema: Preço caiu

**Possível causa:**
- Concorrência aumentou
- Estação/sazonalidade mudou
- Mercado Livre ativou promoção automática

**Solução:**
- Acompanhe preço dos concorrentes (pesquise no ML)
- Ajuste o seu conforme necessário
- Use cupons em vez de reduzir preço base
